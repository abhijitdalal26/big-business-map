# Study pack output

Everything here is regenerated by:

```
python data_analysis/build_report.py
```

| File | What it is |
|---|---|
| `index.html` | **The browsable app** - open this in a browser to study the whole pack with the charts inline. |
| `companies.js` | The company directory behind the app: every company in the universe with its website and links. |
| `STUDY_PACK.md` | The study pack as Markdown - the main deliverable. |
| `study_pack.html` | The same pack as a single self-contained page with the charts inline. |
| `metrics.json` | Every metric and insight line, machine readable. |
| `charts/` | 36 charts, house style. |
| `data/` | 46 tables as CSV. |
